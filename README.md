# 💻 Proyecto 1º DAW - Programación en Java

Repositorio con todas las tareas y ejercicios realizados durante el **primer año de DAW**, organizados por temas para facilitar el acceso y la práctica.

---

## 📂 Estructura del proyecto

Cada carpeta corresponde a un tema o unidad del curso:

```
📁 Tema01_Introduccion
📁 Tema02_Variables
📁 Tema03_EstructurasControl
📁 Tema04_Arrays
📁 Tema05_Funciones
📁 Tema06_POO
📁 Tema07_Ficheros
```

Dentro de cada tema encontrarás:

* 📝 Ejercicios propuestos
* ✅ Soluciones
* 💡 Pruebas o ejemplos adicionales

----

## 🎯 Objetivo

Este repositorio tiene como objetivo:

* Practicar los fundamentos de la programación en Java ☕
* Servir como guía de estudio
* Tener todo el contenido organizado y accesible
* Ver la evolución a lo largo del curso

---

## 🧠 Contenidos trabajados

✔️ Introducción a la programación
✔️ Tipos de datos y variables
✔️ Estructuras de control (if, switch, bucles)
✔️ Arrays y colecciones
✔️ Programación orientada a objetos (POO)
✔️ Manejo de ficheros
✔️ Excepciones

---

## 🚀 Tecnologías utilizadas

* Java ☕
* IntelliJ IDEA / Eclipse
* Git & GitHub

1. Clona el repositorio:
